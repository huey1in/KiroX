# Native runtime dependencies

KiroX's own source is licensed by the root `LICENSE` file.

The native desktop application links dynamically to Qt 6.8.3. Qt source and
third-party notices are available from the official release repositories:

- https://github.com/qt/qtbase/tree/v6.8.3
- https://github.com/qt/qtdeclarative/tree/v6.8.3
- https://github.com/qt/qtsvg/tree/v6.8.3
- https://github.com/qt/qtshadertools/tree/v6.8.3
- https://github.com/qt/qtmultimedia/tree/v6.8.3

The accompanying `qt` directory contains the license texts distributed by
these modules. Qt is distributed as separate shared libraries, permitting
replacement with compatible builds. The application does not impose a
restriction on modifying or debugging those libraries.
Packages also include Qt's SPDX inventories when supplied by the SDK; these
record component versions, copyright notices and source references.

libcurl-impersonate 2.2.3 and its bundled dependencies are distributed with
the SDK's `LICENSE*` files under `curl-impersonate` in an installed package:
https://github.com/lexiforest/curl-impersonate/tree/v2.2.3

Windows uses the operating system's CNG cryptography implementation. Other
platforms link to OpenSSL 3: https://www.openssl.org/source/.
MinGW runtime libraries, when present, are distributed with GCC's runtime
exception: https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html.
The accompanying `mingw` and `openssl` directories contain license texts.

Qt Multimedia packages can include FFmpeg shared libraries. Their LGPL 2.1
license and build licensing notes are included in `ffmpeg`; source is at
https://github.com/FFmpeg/FFmpeg. Exact versions are recorded in Qt's SDK
inventories and the bundled runtime library names.

The completion sound is generated by this repository. System fonts are used
at runtime; copied fonts used by local screenshot tests are not distributed.
